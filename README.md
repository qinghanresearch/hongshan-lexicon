# 红山文化词典 · Hongshan Culture Lexicon

Bilingual reading edition for readers and translators working between Chinese and English. Chinese characters and relevant original terms are retained in the English interface.

- Website: https://qinghanresearch.github.io/hongshan-lexicon/
- Editor: https://hongshan-culture-lexicon.vocal-leaf-8915.chatgpt.site/editor
- About the editor: https://qinghanresearch.github.io/qinghan-website/

This repository contains the public reading pages and their assets. The editor, database, and suggestion service are hosted separately; their source, private drafts, credentials, and reader messages are not included here. The explanatory prose remains subject to scholarly review.

## Updates

GitHub Pages publishes the root of the default branch. Commit and push updated exported reading pages with GitHub Desktop. Editing the separate editorial service does not automatically refresh this static edition; export and push the revised pages after editorial approval. Do not upload private notes or database backups into this repository.
